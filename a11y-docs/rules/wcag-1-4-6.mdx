## What it checks

WCAG 1.4.6 requires that text has even higher contrast against its background than the standard AA requirement. Like [1.4.3 Contrast (Minimum)](/rules/wcag-1-4-3), a11y audits both DOM text and text embedded inside images.

## Contrast thresholds (WCAG AAA)

| Text size | Required contrast ratio |
|-----------|------------------------|
| Normal text (< 18 pt / < 14 pt bold) | **7 : 1** |
| Large text (≥ 18 pt / ≥ 14 pt bold) | **4.5 : 1** |

## How it works

This rule uses the exact same pipeline as [1.4.3 Contrast (Minimum)](/rules/wcag-1-4-3), including the **Unified Pipeline** for DOM text and the **Multimodal OCR Pipeline** for images of text, but applies the stricter AAA thresholds.

Findings for 1.4.6 are only emitted when the audit is submitted with `wcag_level="AAA"`.

## False Positive Protection

The same protections from the 1.4.3 engine apply here:
*   **Background Color Resolution**: Correctly handles transparent wrappers by traversing up the DOM.
*   **Classification Exemptions**: Automatically ignores logos and decorative graphics.
*   **Opacity Blending**: Accounts for semi-transparent foregrounds and backgrounds.

## Suggested fix

Ensure all text meets the higher 7:1 contrast ratio.

```css
/* FAILED (passes AA but fails AAA) */
.text {
  color: #767676; /* 4.5:1 on white */
}

/* PASSED (AAA compliant) */
.text {
  color: #595959; /* 7.0:1 on white */
}
```
