### 1.1.1 — Non-text Content (Level A)
**Check:** `alttext.py`

#### Flowchart
```mermaid
flowchart TD
    START["Image Metadata + OCR"] --> CLASS{"Classification?"}
    CLASS -- Decorative --o DEC["alt = empty?"]
    CLASS -- Informative --o INF["Alt matches OCR?"]
    CLASS -- Logo --o LOG["Alt contains 'logo'/'home'?"]
    CLASS -- Icon --o ICO["Alt describes action/icon?"]
    CLASS -- Button --o BTN["Alt describes action?"]
    
    DEC -- Yes --> PASS["PASS"]
    DEC -- No --> FAIL1["FAIL: 1.1.1 Decorative needs empty alt"]
    
    INF -- Match --> PASS
    INF -- No Match --> FAIL2["FAIL: 1.1.1 OCR words missing in alt"]
    
    LOG -- Yes --> PASS
    LOG -- No --> FAIL3["FAIL: 1.1.1 Logo needs 'logo'/'home' text"]
    
    ICO -- Yes --> PASS
    ICO -- No --> FAIL4["FAIL: 1.1.1 Icon needs purpose/qualifier"]
    
    BTN -- Yes --> PASS
    BTN -- No --> FAIL5["FAIL: 1.1.1 Button needs action word"]
```

#### Cases Covered
| Case | Detection Method |
|------|-----------------|
| Decorative alt transparency | Strictly enforces `alt=""` |
| Informative content parity | OCR word-match (3+ chars) |
| Branding logotypes | Keyword check ('logo', 'home') |
| Social/Action icons | "Brand icon" or "Close" keyword match |
| Button purpose | Action word regex (`_BUTTON_ACTION_WORDS`) |

#### Cases Missed / False Negative Risks
| Case | Why missed |
|------|-----------|
| Short OCR tokens | Tokens < 3 characters are ignored to avoid noise |
| Complex diagrams | Heuristic only checks if alt is non-empty |
| Image-map areas | Not explicitly audited in `alttext.py` |

### 1.3.4 — Orientation (Level AA)
**Check:** `orientation.py`

#### Flowchart
```mermaid
flowchart TD
    SNAP["Portrait + Landscape Snapshots"] --> ORE{"Overlay Detected?"}
    ORE -- Yes --> REV1["NEEDS_REVIEW: Rotate device overlay"]
    ORE -- No --> CCO{"Missing Content?"}
    
    CCO -- Yes --> REV2["NEEDS_REVIEW: Hidden main content"]
    CCO -- No --> CLO{"CSS Lock?"}
    
    CLO -- Yes --> REV3["NEEDS_REVIEW: transform rotation"]
    CLO -- No --> SCR{"Scroll Induced?"}
    
    SCR -- Yes --> REV4["NEEDS_REVIEW: landscape horizontal scroll"]
    SCR -- No --> CNT{"Element Count mismatch?"}
    
    CNT -- "< 50% ratio" --> REV5["NEEDS_REVIEW: functionality hidden"]
    CNT -- OK --> PASS["PASS"]
```

#### Cases Covered
| Case | Detection |
|------|-----------|
| Rotate-device overlays | Regex `detect_rotate_overlay` |
| CSS body locks | `detect_css_transform_lock` |
| Content clipping | `detect_body_overflow_hidden` |
| Responsive breakage | `detect_landscape_horizontal_overflow` |
| Functionality loss | Comparative focusable element count |

#### Cases Missed
| Case | Why |
|------|-----|
| Meta viewport locks | Not checked in rendered evaluator |
| JS `orientation.lock()` | Hard to detect without side-channel monitoring |

### 1.4.3 — Contrast (Minimum) (Level AA)
**Check:** `contrast_analyser.py` (Multimodal)

#### Flowchart
```mermaid
flowchart TD
    IMG["Image of Text / Element Crop"] --> SEG["Segmentation (Otsu)"]
    SEG --> L["Calculate Relative Luminance (L1, L2)"]
    L --> SIZE{"Large Text?"}
    
    SIZE -- "Yes (>=24px/18.5px+B)" --> L30{"Ratio >= 3.0:1?"}
    SIZE -- "No" --> L45{"Ratio >= 4.5:1?"}
    
    L30 -- "Yes" --> PASS["PASS"]
    L30 -- "No" --> FAIL1["FAIL: 1.4.3 Contrast below 3:1"]
    
    L45 -- "Yes" --> PASS
    L45 -- "No" --> FAIL2["FAIL: 1.4.3 Contrast below 4.5:1"]
```

#### Cases Covered
| Case | Detection |
|------|-----------|
| Text in images (OCR-led) | `analyze_text_region` |
| Large text exemption | 24px regular / 18.5px bold threshold |
| Color-space accuracy | sRGB to Linear luminance conversion |

#### Cases Missed
| Case | Why |
|------|-----|
| Complex backgrounds | Segmentation (Otsu) may fail on high-noise gradients |
| Multi-color text | Color averaging doesn't catch per-character contrast |

### 1.4.4 — Resize Text (Level AA)
**Check:** `resize_text.py`

#### Flowchart
```mermaid
flowchart TD
    BASE["Baseline + 200% Zoom"] --> FILT["Perceivable Text Elements"]
    FILT --> SCR{"Page Scroll?"}
    SCR -- New Horizontal --> FAIL1["FAIL: 1.4.4 Page-level reflow break"]
    SCR -- No --> CLIP{"New Clipping?"}

    CLIP -- No --> PASS["PASS"]
```

#### Cases Covered
| Case | Detection |
|------|-----------|
| Text container truncation | `scrollWidth` > `clientWidth` diffing |
| Page-level horizontal scroll | `document_scroll_width` comparison |
| Ghosting/Invisibility | Perceivable elements heuristic |

#### Cases Missed
| Case | Why |
|------|-----|
| Vertical clipping | Only horizontal/document scroll checked |
| Overlapping text | Bounding box intersection not in this rule |

#### Cases Missed
- Components at page edges (flagged as INCOMPLETE).
- Components with complex gradients/patterns.
