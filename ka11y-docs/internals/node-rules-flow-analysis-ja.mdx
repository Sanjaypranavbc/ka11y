### 1.2.1 — 音声のみ・映像のみのコンテンツ（レベル A）
**チェック:** `audio-transcript.check.js`

#### フローチャート
```mermaid
flowchart TD
    AUD["audio 要素"] --> TRK{"track 要素あり？"}
    TRK -- Yes --> PASS["PASS"]
    TRK -- No --> LNK{"コンテナ内にトランスクリプトリンクあり？"}
    LNK -- Yes --> PASS
    LNK -- No --> FIG{"figcaption あり？"}
    FIG -- Yes --> PASS
    FIG -- No --> DET{"details でトランスクリプトあり？"}
    DET -- Yes --> PASS
    DET -- No --> ARIA{"aria-describedby あり？"}
    ARIA -- Yes --> PASS
    ARIA -- No --> INC["INCOMPLETE: トランスクリプトなし"]
```

#### カバーするケース
| ケース | 検出方法 |
|------|-----------------|
| VTT / SRT トラック要素 | `<audio>` 内の `<track>` |
| トランスクリプトリンク | 兄弟/親アンカーの "transcript" キーワード |
| `<figcaption>` キャプション | figure 内の figcaption |
| 折りたたみ details | トランスクリプト内容の `<details>` |
| ARIA 説明参照 | `aria-describedby` → トランスクリプトブロック |

#### カバーできないケース
| ケース | 理由 |
|------|-----|
| アコーディオン内トランスクリプト | 非表示コンテンツを評価しない |
| 認証が必要なトランスクリプト | 外部リンク先を追わない |
| iframe 内トランスクリプト | クロスオリジン iframe アクセス不可 |

### 1.3.2 — 意味のある読み順（レベル A）
**チェック:** `meaningful-sequence.check.js`

#### フローチャート
```mermaid
flowchart TD
    CONT["Flex/Grid コンテナ（最大 500）"] --> RTL{"RTL ドキュメント？"}
    RTL -- "Yes + row-reverse" --> PASS["PASS（RTL 免除）"]
    RTL -- No --> FLEX{"flex-direction が反転？"}
    FLEX -- Yes --> INC1["INCOMPLETE: 視覚的順序の不一致"]
    FLEX -- No --> ORD{"CSS order プロパティ設定あり？"}
    ORD -- Yes --> INC2["INCOMPLETE: order による並び替え検出"]
    ORD -- No --> GRID{"グリッド配置の不一致？"}
    GRID -- Yes --> INC3["INCOMPLETE: グリッドレイアウトの並び替え"]
    GRID -- No --> FLT{"フロートと隣接ブロックの混在？"}
    FLT -- Yes --> INC4["INCOMPLETE: フロートの混在"]
    FLT -- No --> PASS
```

#### カバーするケース
| ケース | 検出 |
|------|-----------|
| flex-direction 反転 | `row-reverse` / `column-reverse` 検出 |
| CSS `order` による並び替え | ゼロ以外の order 値をフラグ |
| グリッド列配置 | 明示的な `grid-column` / `grid-row` の不一致 |
| フロートの混在 | フロート + ブロックの兄弟要素 |
| RTL 免除 | `dir="rtl"` / `lang="ar/he/fa"` ページは `row-reverse` を免除 |

#### カバーできないケース
| ケース | 理由 |
|------|-----|
| 絶対位置による並び替え | Flex/Grid スキャン外 |
| CSS Transform による視覚的並び替え | Transform を検査しない |
| RTL 上の `column-reverse` | 依然として違反としてフラグ立て |

#### フローチャート
```mermaid
flowchart TD
    MAN["Web App Manifest"] --> MLOCK{"orientation がロックされている？"}
    MLOCK -- Yes --> FAIL1["FAIL: 1.3.4 Manifest による方向ロック"]
    MLOCK -- No --> SCRPT{"スクリプトに screen.orientation.lock() あり？"}

    CSS -- No --> META{"viewport に orientation= または max-scale=1 あり？"}
    META -- Yes --> FAIL3["FAIL: 1.3.4 viewport ロック"]
    META -- No --> WM{"writing-mode: vertical-* あり？"}
    WM -- Yes --> INC2["INCOMPLETE: 縦書きモードの制限"]
    WM -- No --> PASS["PASS"]
```

#### カバーするケース
| ケース | 検出 |
|------|-----------|
| Manifest による方向ロック | `manifest.json` の `orientation` フィールド |
| スクリプトによる方向ロック | インラインスクリプトの `screen.orientation.lock()` |

| 縦書きモード | body の `writing-mode: vertical-*` |

| ケース | 理由 |
|------|-----|
| ページ読み込み後のプログラム的方向変更 | ページ読み込み時に検出不可 |
| 外部スクリプトによる方向ロック | インラインスクリプトのみスキャン |

### 2.4.7 — フォーカス可視性（レベル AA）

```mermaid
flowchart TD
    ELEM["フォーカス可能要素（最大 100）"] --> CAP1["フォーカス前スタイルをキャプチャ"]

    DIFF -- "なし" --> FAIL["FAIL: 2.4.7 フォーカスインジケーターが見えない"]
```

#### カバーするケース
| ケース | 検出 |
|------|-----------|
| アウトライン表示 | `outline` プロパティの差分 |
| ボックスシャドウ | `box-shadow` の差分 |

| ケース | 理由 |

| 疑似要素インジケーター | `::before`/`::after` 注入フォーカススタイル |
