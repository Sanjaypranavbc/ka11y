### Localization and Shared Config

Current Node output behavior:

- grouped and flat endpoints both accept `lang`
- WCAG names and suggested fixes come from shared `i18n/rules.yml` plus optional locale overlays
- axe-core summaries are normalized through the locale-aware mapper so Japanese failure summaries no longer leak English prefixes into `reason`
- migrated custom checks receive shared rule context and can read EN/JA heuristics and reason templates from `config/universal.yml`

This means Japanese Node findings now localize all user-facing finding text that is owned by the Node mapper:

- `criterion_name`
- `reason`
- `suggested_fix`

### 1.2.1 — Audio-only and Video-only (Level A)
**Check:** `audio-transcript.check.js`

#### Flowchart
```mermaid
flowchart TD
    AUD["audio elements"] --> TRK{"track element?"}
    TRK -- Yes --> PASS["PASS"]
    TRK -- No --> LNK{"Transcript link in container?"}
    LNK -- Yes --> PASS
    LNK -- No --> FIG{"figcaption present?"}
    FIG -- Yes --> PASS
    FIG -- No --> DET{"details with transcript?"}
    DET -- Yes --> PASS
    DET -- No --> ARIA{"aria-describedby?"}
    ARIA -- Yes --> PASS
    ARIA -- No --> INC["INCOMPLETE: No transcript found"]
```

#### Cases Covered
| Case | Detection Method |
|------|-----------------|
| VTT / SRT track elements | `<track>` inside `<audio>` |
| Transcript links | Sibling/parent anchor with "transcript" keyword |
| `<figcaption>` captions | Adjacent figcaption in figure |
| Collapsed details | `<details>` with transcript content |
| ARIA description | `aria-describedby` pointing to transcript block |

#### Cases Missed
| Case | Why |
|------|-----|
| Transcript in collapsed accordion | Hidden content not evaluated |
| Transcript behind auth | External link resolution not followed |
| Transcript inside iframe | Cross-origin iframe content inaccessible |


#### Cases Covered
| Case | Detection |
