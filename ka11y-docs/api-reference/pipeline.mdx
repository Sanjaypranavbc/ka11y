<Warning>
  The pipeline endpoint is **synchronous and blocking**. For production use, prefer the [Combined endpoint](/api-reference/combined) which is async, non-blocking, and supports SSE streaming.
</Warning>

The pipeline endpoint runs all auditors sequentially and returns the full result in a single HTTP response. It is useful for scripting and CI environments where you want one call with a complete result.

---

## POST /api/v1/pipeline/

**Request body** is identical to the [Combined endpoint](/api-reference/combined#submit-an-audit).

### 11-step execution order

| Step | Name | WCAG SC | Description |
|------|------|---------|-------------|
| 1 | Image Crawl | — | Playwright crawls `<img>`, `<svg>`, buttons, background images |
| 2 | OCR | — | EasyOCR detects text in crawled images (if `run_ocr: true`) |
| 3 | Image Audit | 1.1.1 | Alt-text quality check |
| 4 | Form Crawl | — | Playwright extracts form fields and their accessible-name sources |
| 5 | Form Audit | 3.3.1, 3.3.2 | Label, error-message, and autocomplete checks |
| 6 | Interactive Element Crawl | — | Playwright extracts buttons, links, ARIA interactive elements |
| 7 | Label-in-Name Audit | 2.5.3 | Accessible name must contain visible label |
| 8 | Moving Content Crawl | — | Detects carousels, CSS animations, autoplay video, animated GIFs |
| 9 | Pause/Stop/Hide Audit | 2.2.2 | Checks for pause/stop mechanisms |
| 10 | Target Size Crawl | — | Measures rendered dimensions of interactive elements |
| 11 | Target Size Audit | 2.5.8 | Flags elements below 24 × 24 CSS px |
