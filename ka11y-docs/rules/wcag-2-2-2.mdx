## What it checks

Any content that moves, blinks, scrolls, or auto-updates for more than 5 seconds must have a mechanism to pause, stop, or hide it.

## What axe-core misses

axe-core only flags `<blink>` and `<marquee>` — both deprecated HTML elements rarely used in modern sites. ka11y detects:

| Content type | Detection method |
|-------------|-----------------|
| `video_autoplay` | `<video autoplay>` element |
| `animated_gif` | `<img src="*.gif">` |
| `css_animation` | Running WAAPI / CSS animations via `document.getAnimations()` — infinite loop (`iterationCount === Infinity`) |
| `carousel_autoplay` | Bootstrap, Swiper, Slick, Owl Carousel, Flickity, Glide.js, Splide — detected via class names and `data-*` attributes |
| `marquee` | `<marquee>` (legacy) |
| `blink` | `<blink>` (legacy) |

## Applicability gates

All three must be true for a **violation** to be raised:

1. **Starts automatically** — autoplay, CSS animation on page load, carousel auto-advances
2. **Duration > 5 s or infinite** — very short one-shot transitions are excluded
3. **No mechanism** — no `controls` attribute, no adjacent button containing pause/stop/play text, no ARIA control

## The `axe_would_catch` field

Each finding carries `axe_would_catch: bool`. Use this to filter for novel detections:

```json
{
  "axe_would_catch": false,
  "status": "fail",
  "reason": "Autoplay carousel has no pause mechanism (Swiper detected via .swiper-container)",
  "element": { "html": "<div class=\"swiper-container\" data-autoplay=\"3000\">…" }
}
```

When `axe_would_catch` is `false`, the finding is something axe-core would have missed entirely.

## Common violations

| Type | Example |
|------|---------|
| Autoplay video | `<video autoplay loop src="hero.mp4">` without `controls` |
| Animated GIF | `<img src="loading-animation.gif">` in a persistent hero section |
| CSS animation | `animation: slide 2s linear infinite` with no pause button |
| Carousel | Bootstrap `.carousel[data-ride="carousel"]` with no pause-on-hover |

## Suggested fix

```html
<!-- Video — add controls -->
<video autoplay loop src="hero.mp4" controls>
  <track kind="captions" src="captions.vtt">
</video>

<!-- Carousel — add pause button -->
<div class="carousel" data-ride="carousel">
  <button type="button" data-bs-target=".carousel" data-bs-slide="pause"
          aria-label="Pause slideshow">
    Pause
  </button>
  <!-- slides -->
</div>

<!-- CSS animation — provide control -->
<button id="pause-anim" aria-pressed="false">Pause animation</button>
<div class="animated-banner" aria-live="off">…</div>
<script>
  document.getElementById('pause-anim').addEventListener('click', e => {
    const banner = document.querySelector('.animated-banner');
    const paused = e.target.getAttribute('aria-pressed') === 'true';
    banner.style.animationPlayState = paused ? 'running' : 'paused';
    e.target.setAttribute('aria-pressed', String(!paused));
  });
</script>
```
