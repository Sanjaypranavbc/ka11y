The `/combined/{job_id}/stream` endpoint delivers real-time audit progress via Server-Sent Events (SSE). This page shows how to consume it from different environments.

---

## Browser (JavaScript / TypeScript)

```typescript
async function runAudit(url: string) {
  // 1. Submit the job
  const res = await fetch("/api/v1/combined/", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ url, wcag_level: "AA" }),
  });
  const { job_id } = await res.json();

  // 2. Open SSE stream
  const es = new EventSource(`/api/v1/combined/${job_id}/stream`);

  es.addEventListener("stage_start", (e) => {
    const { stage_name } = JSON.parse(e.data);
    console.log(`▶ started: ${stage_name}`);
  });

  es.addEventListener("stage_complete", (e) => {
    const { stage_name, findings_count } = JSON.parse(e.data);
    console.log(`✓ ${stage_name}: ${findings_count} findings`);
  });

  es.addEventListener("stage_error", (e) => {
    const { stage_name, error } = JSON.parse(e.data);
    console.warn(`✗ ${stage_name} failed: ${error}`);
  });

  es.addEventListener("job_complete", async (e) => {
    es.close();
    const { job_id } = JSON.parse(e.data);
    // Fetch full result
    const full = await fetch(`/api/v1/combined/${job_id}`).then(r => r.json());
    console.log("Done:", full.result.summary);
  });

  es.addEventListener("job_failed", (e) => {
    es.close();
    const { error } = JSON.parse(e.data);
    console.error("Job failed:", error);
  });

  es.onerror = () => {
    es.close();
    console.warn("SSE connection lost — falling back to polling");
    // implement polling fallback here
  };
}
```

## Python (asyncio)

```python
import asyncio
import httpx
import json

async def stream_audit(url: str):
    base = "http://localhost:8000/api/v1"

    # Submit
    async with httpx.AsyncClient() as client:
        resp = await client.post(f"{base}/combined/", json={"url": url, "wcag_level": "AA"})
        job_id = resp.json()["job_id"]

    # Stream
    async with httpx.AsyncClient(timeout=None) as client:
        async with client.stream("GET", f"{base}/combined/{job_id}/stream") as stream:
            async for line in stream.aiter_lines():
                if line.startswith("event:"):
                    event_type = line.removeprefix("event:").strip()
                elif line.startswith("data:"):
                    data = json.loads(line.removeprefix("data:").strip())
                    print(f"{event_type}: {data}")
                    if event_type in ("job_complete", "job_failed"):
                        break

asyncio.run(stream_audit("https://example.com"))
```

## Nginx configuration

SSE requires specific nginx proxy settings. These are already configured in `ka11y-frontend-sdk/nginx.conf`:

```nginx
# Must appear BEFORE the generic /api/ location
location ~ ^/api/v1/combined/.+/stream$ {
    proxy_pass         http://python:8000;
    proxy_http_version 1.1;
    proxy_set_header   Connection "";
    proxy_buffering    off;          # critical — disable output buffering
    proxy_cache        off;
    proxy_read_timeout 3600s;        # keep alive for long audits
    chunked_transfer_encoding on;
}
```

<Warning>
  `proxy_buffering off` is required. Without it, nginx will buffer the entire response and the client won't receive events until the connection closes.
</Warning>

## Heartbeat keepalive

The server sends a comment line every 25 seconds to prevent proxy and load balancer timeouts:

```
: keepalive
```

Comment lines are not dispatched as events and can be ignored by `EventSource`. They are visible in raw `curl` output.

## Late connect behaviour

If a client connects after the job has already started:

1. The generator immediately checks `_jobs[job_id]["status"]`.
2. If `"completed"` → sends `job_complete` event and closes.
3. If `"failed"` → sends `job_failed` event and closes.
4. If `"running"` → sends a `job_state` event with the current `current_stage` and `stages[]` array, then continues streaming future events normally.

This means it is safe to connect slightly after submission without missing any events.
